# Hungry Hero 🎮

**Hungry Hero** is a 2D action-platformer game made with **Unity and C#**.

I created this project around **3 years ago** as a personal learning project while experimenting with Unity and game development. It was built by me while learning and experimenting with different game development concepts, rather than following a YouTube tutorial.

> ⚠️ This is an older learning project and is preserved as part of my development journey.

## 🎮 About the Game

Hungry Hero is a 2D platformer focused on exploration, platforming, combat, and collecting items.

The player can move through different environments, fight enemies, interact with the game world, and collect items while progressing through the game.

## ✨ Features

- 2D player movement
- Platforming mechanics
- Combat system
- Enemy interactions
- Player health system
- Enemy health system
- Enemy health bars
- Collectible items
- 2D physics and collisions
- Animations
- Multiple environments
- Basic enemy behavior

## 🛠️ Technologies

- **Unity**
- **C#**
- Unity 2D Physics
- Unity Animation System

## 🎯 Purpose

The main purpose of Hungry Hero was **learning and experimentation**.

I built this project to gain practical experience with Unity and C# and to understand how different game systems work together.

Since this was one of my earlier projects, the code and architecture may not represent my current programming practices. I am keeping the project as a record of my progress and development journey.
